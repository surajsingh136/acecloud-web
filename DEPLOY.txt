--------------------------------------------------------
STEP 1 - Create a repo on GitHub
--------------------------------------------------------
1. https://github.com  ->  create a free account (no card needed).
2. New repository -> name: acecloud-web  (do NOT add a README).
3. Open a terminal in this folder (in the folder's address bar type: cmd)
   and run these (use your own username):

   git init
   git add -A
   git commit -m "deploy"
   git remote add origin https://github.com/<USERNAME>/acecloud-web.git
   git branch -M main
   git push -u origin main

--------------------------------------------------------
STEP 2 - Deploy on Render.com
--------------------------------------------------------
1. https://render.com  ->  "Get Started"  ->  "Sign up with GitHub".  (NO CARD)
2. Dashboard -> New + -> Blueprint -> select the "acecloud-web" repo -> Apply.
3. When it asks for environment variables, enter these:
      ACEWEB_PIN      = your 4-6 digit pin (e.g. 4821)
      ACECLOUD_EMAIL  = your acecloud email
      ACECLOUD_PASSWD = your acecloud password
4. Let it deploy. You'll get a live URL:
      https://acecloud-web.onrender.com

--------------------------------------------------------
IMPORTANT NOTES
--------------------------------------------------------
- Render FREE sleeps after 15 min of no traffic.
  The first load takes 30-50 sec, then it is normal. You can access it anytime.
- Keep the PIN STRONG, otherwise anyone who knows the URL can create/delete paid VMs.
- Put the email/password only in Render's Environment variables,
  never in the code / GitHub.
