--------------------------------------------------------
STEP 1 - Create a repo on GitHub
--------------------------------------------------------
1. https://github.com  ->  create a free account (no card needed).
2. New repository -> name: acecloud-web  (do NOT add a README).
3. Open a terminal in this folder (in the folder's address bar type: cmd)
   and run these (use your own username):

   git init
   git add -A
   git commit -m "deploy"
   git remote add origin https://github.com/<USERNAME>/acecloud-web.git
   git branch -M main
   git push -u origin main

--------------------------------------------------------
STEP 2 - Deploy on Render.com
--------------------------------------------------------
1. https://render.com  ->  "Get Started"  ->  "Sign up with GitHub".  (NO CARD)
2. Dashboard -> New + -> Blueprint -> select the "acecloud-web" repo -> Apply.
3. When it asks for environment variables, enter these:
      ACEWEB_PIN      = your 4-6 digit pin (e.g. 4821)
      ACECLOUD_EMAIL  = your acecloud email
      ACECLOUD_PASSWD = your acecloud password
      HOSTZOP_APIKEY  = (optional) your hostzop.com API key
      EXCLOUD_APIKEY  = (optional) your excloud.in API key (sk-excloud-...)
      GCORE_APIKEY    = (optional) your gcore.com API key
      GCORE_REGION_ID = (optional) your gcore region id (default 108 = Mumbai)
4. Let it deploy. You'll get a live URL:
      https://acecloud-web.onrender.com

--------------------------------------------------------
HUB  /  MULTI-ACCOUNT  (/all)
--------------------------------------------------------
- Open  https://<your-app>.onrender.com/all  for the hub (ACECLOUD logo).
- Click the AceCloud card to add/select accounts (label, email, password, optional API key).
- "Current (default)" account comes from env (ACECLOUD_EMAIL / ACECLOUD_PASSWD) and is
  read-only - it is never modified.
- Accounts added in the UI are saved to spot/accounts.json. Render's free disk is
  ephemeral, so they are lost on restart/redeploy. To keep extra accounts permanently,
  set the ACECLOUD_ACCOUNTS env var to a JSON list, e.g.:
      ACECLOUD_ACCOUNTS=[{"label":"Office","email":"a@b.com","password":"pw","api_key":""}]
- The manager itself stays at  https://<your-app>.onrender.com/  (unchanged).

--------------------------------------------------------
HOSTZOP  (/hostzop)
--------------------------------------------------------
- Open  https://<your-app>.onrender.com/all  ->  click the Hostzop card (next to AceCloud).
  It opens  https://<your-app>.onrender.com/hostzop  (Hostzop manager).
- Hostzop uses an API key (no email/password). In the Accounts tab paste the API key
  (create a token in the hostzop.com UI), optionally Billing account id + Location,
  then "Verify API key" and "Save account".
- The default hostzop account comes from the HOSTZOP_APIKEY env var (read-only).
  Extra accounts are saved to spot/hostzop.json (ephemeral). To keep them permanently
  set HOSTZOP_ACCOUNTS to a JSON list, e.g.:
      HOSTZOP_ACCOUNTS=[{"label":"Main","apikey":"XXXX","billing_account_id":"129754","location":"chn01"}]
- Create Servers tab: pick OS / size / server class / count -> creates Ubuntu Squid proxies
  (ip:port:user:pass) or Windows RDP servers. Delete Selected / Delete All stops billing.
- Proxy list is appended to spot/hostzop_proxy.txt (Linux) on the server.

--------------------------------------------------------
EXCLOUD  (/excloud)
--------------------------------------------------------
- Open  https://<your-app>.onrender.com/all  ->  click the ExCloud card (next to Hostzop).
  It opens  https://<your-app>.onrender.com/excloud  (ExCloud manager).
- ExCloud uses an API key (sk-excloud-...). In the Keys dialog paste the API key,
  optionally Zone id / Subnet id, then "Verify key" and "Save account".
- The default excloud account comes from the EXCLOUD_APIKEY env var (read-only).
  Extra accounts are saved to spot/excloud.json (ephemeral). To keep them permanently
  set EXCLOUD_ACCOUNTS to a JSON list, e.g.:
      EXCLOUD_ACCOUNTS=[{"label":"Main","apikey":"sk-excloud-XXXX","zone_id":"1","subnet_id":"2436"}]
- Pick Image + Instance Type (rate shown) + Disk GB + Subnet -> creates Ubuntu Squid
  proxies (ip:port:user:pass) or Windows RDP servers (cloud-init sets up squid + root).
  Delete Selected / Delete All stops billing. Snapshots create clone templates.
- Proxy list is appended to spot/excloud_proxy.txt (Linux) on the server.
- API bases: https://compute.excloud.in  +  https://iam.excloud.in  (Bearer auth).

--------------------------------------------------------
GCORE  (/gcore)
--------------------------------------------------------
- Open  https://<your-app>.onrender.com/all  ->  click the Gcore card (next to ExCloud).
  It opens  https://<your-app>.onrender.com/gcore  (Gcore manager).
- Gcore uses an API key. In the Keys dialog paste the API key, optionally Project id /
  Region id (default 108 = Mumbai), then "Verify key" and "Save account".
- The default gcore account comes from the GCORE_APIKEY env var (read-only).
  Extra accounts are saved to spot/gcore.json (ephemeral). To keep them permanently
  set GCORE_ACCOUNTS to a JSON list, e.g.:
      GCORE_ACCOUNTS=[{"label":"Main","apikey":"XXXX","project_id":"371709","region_id":"108"}]
- Pick Region + Image + Instance Size + Disk GB -> creates Ubuntu Squid proxies
  (ip:port:user:pass) or Windows RDP servers. Delete Selected / Delete All stops billing.
- Proxy list is appended to spot/gcore_proxy.txt (Linux) on the server.
- API base: https://api.gcore.com/cloud  (Authorization: APIKey <key>).
- Note: prices may be hidden if billing is not enabled on the account (rate shows blank).

--------------------------------------------------------
IMPORTANT NOTES
--------------------------------------------------------
- Render FREE sleeps after 15 min of no traffic.
  The first load takes 30-50 sec, then it is normal. You can access it anytime.
- Keep the PIN STRONG, otherwise anyone who knows the URL can create/delete paid VMs.
- Put the email/password only in Render's Environment variables,
  never in the code / GitHub.
