Getting started

Follow these steps once. After that you can create machines from any cloud on the hub.

Open the hub

After signing in, your default screen opens. Click → the site card for the cloud you want (AceCloud, Hostzop, ExCloud or Gcore).

Add an account

Inside a site click Configure, then fill the API key / login fields and press Save account. Press Use to make it the active account.

Create a machine

Set the Hours box to auto-delete later (or leave 0 to keep it). Click Create. A live Time left countdown appears next to every machine.

Copy details

Click any IP, proxy or password in the table to copy it instantly, or use the Copy IP / Copy Proxy / Copy Password / Copy RDP Pass buttons above the table.

Pick your default home screen

On the hub, press Set as default on any card. Next time / opens, that cloud loads first. You can change it any time.

Tip: every user only sees their own accounts. Your keys are never shown to other users.

Where to find your keys / IDs

Each cloud gives you credentials on its own dashboard. Copy them into the matching fields.
